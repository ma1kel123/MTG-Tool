# MTG Tool V2.2 Integrated Alpha

This is the first connected phone-test milestone.

Connected workflow:
1. Deck Library: import/persist a deck locally.
2. Analyze: basic normalized analysis + Deck DNA fixture layer.
3. Simulate: 4/5/6-player synthetic pod environment stress test.
4. Improve: virtual package recommendation + new deck version snapshot.
5. Play: quick table/life-counter flow using the selected saved deck.

GitHub Pages support:
- all URLs are relative (`./`)
- `.nojekyll` included
- service worker included
- PWA manifest included
- static files only; no server required

Important:
The analysis/simulation/recommendation values beyond simple card counting are still alpha fixture/model values used to validate the integrated product workflow. They are not final measured MTG recommendations.

For GitHub Pages, upload the CONTENTS of this folder to the repository root so `index.html` is at the root.
